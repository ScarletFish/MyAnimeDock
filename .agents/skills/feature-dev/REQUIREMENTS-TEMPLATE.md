## 填写示例

### 一句话描述
为 MyList 添加批量状态修改功能

### 解决什么问题
用户想一次性把 10 部"想看"的番标记为"在看"，目前只能逐个操作

### 验收标准
- [ ] 在 MyList 视图可以勾选多个条目
- [ ] 勾选后显示批量操作按钮
- [ ] 点击"批量修改状态"弹出状态选择弹窗
- [ ] 确认后所有选中条目的状态被更新
- [ ] 操作完成后显示成功 toast，显示修改数量

### 边界情况
- [x] 空选择：未勾选任何条目时按钮禁用
- [x] 全选：跨页全选正确处理
- [ ] 网络错误：部分失败时显示失败数量

### 影响范围
| 文件 | 操作 | 说明 |
|------|------|------|
| public/js/mylist.js | 修改 | 添加多选逻辑和批量操作 UI |
| server/server.js | 修改 | 新增 POST /api/mylist/batch 接口 |
| public/css/views.css | 修改 | 添加多选样式 |

### 非目标
- 不做跨视图批量操作（仅限 MyList 内）
- 不做自动状态流转（需要手动选择）
