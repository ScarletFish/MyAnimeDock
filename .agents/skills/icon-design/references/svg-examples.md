# SVG代码规范与示例

## 基本规范

### viewBox标准
```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
```

### 命名规范
- 文件名: `icon-{name}.svg` (kebab-case)
- ID: `icon-{name}`

### 代码规范
- 使用 `currentColor` 作为fill/stroke值
- 不设置固定 width/height
- 使用语义化的 group (`<g>`) 组织元素
- 路径数据尽量简洁
- 优先使用基础图形元素 (circle, rect, polygon, line, path)
