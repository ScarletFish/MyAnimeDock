# 风格模板库

## S1: 现代极简风 (Modern Minimal)

```
类型: 线性 / 单色面性
线宽: 1.5-2px
圆角: 小圆角 (2px)
色彩: 单色或双色，低饱和度
质感: 纯扁平，无阴影无渐变
形状: 几何化，简洁概括
调性: 专业、冷静、高效
```

**适用场景**: SaaS产品、B端后台、企业管理工具、专业软件、金融科技
**Prompt关键词**: `minimalist line icon, thin stroke, geometric, clean, professional, single color, flat design, no shadows`
**样例Prompt**: `minimalist line icon of a dashboard chart, 1.5px stroke weight, small rounded corners, single navy blue color #2563EB, flat design, clean geometric shapes, transparent background, 24x24px, professional UI icon`

---

## S2: 活力渐变风 (Vibrant Gradient)

```
类型: 面性 / 线面结合
线宽: 2-2.5px
圆角: 中等圆角 (4-6px)
色彩: 多色渐变，高饱和度
质感: 线性渐变或径向渐变
形状: 有机圆润，略带动感
调性: 活力、年轻、创新
```

**适用场景**: 社交App、娱乐产品、在线教育、音乐视频、直播平台
**Prompt关键词**: `vibrant gradient icon, colorful, playful, modern, rounded shapes, energetic`
**样例Prompt**: `vibrant gradient icon of a music note, rounded shapes, purple to pink gradient #7C3AED to #EC4899, modern flat design with subtle gradient, 24x24px, transparent background, playful UI icon`

---

## S3: 毛玻璃新拟态风 (Glassmorphism / Neumorphism)

```
类型: 面性 / 轻质感
线宽: 1-1.5px (若有描边)
圆角: 大圆角 (8-12px)
色彩: 半透明，柔和色调
质感: 毛玻璃效果，轻阴影，半透明叠加
形状: 圆润柔和，胶囊/圆形
调性: 高端、精致、现代
```

**适用场景**: iOS风格App、现代Web应用、健康管理、生活方式App
**Prompt关键词**: `glassmorphism icon, frosted glass effect, soft shadows, translucent, neumorphic, rounded`
**样例Prompt**: `glassmorphism icon of a heart health monitor, frosted glass effect, soft inner shadow, light blue translucent background, rounded corners 10px, 24x24px, transparent background, iOS style UI icon`

色彩: 丰富色彩，光影层次

**样例Prompt**: `pixel art icon of a game controller, 8-bit retro style, limited color palette with cyan and magenta, blocky shapes, 24x24px, transparent background, game UI icon`
