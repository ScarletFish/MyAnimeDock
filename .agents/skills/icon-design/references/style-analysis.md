# 风格分析维度

## 分析流程

当用户通过 `+iconscan` 提供网站URL或截图时，按以下维度进行系统化分析。

---

## 维度1: 色彩分析 (Color Analysis)

### 提取内容
- **主色调**: 页面中最突出的颜色（通常来自Logo、按钮、导航栏）
- **辅助色**: 次要使用的颜色（链接、图标、标签）
- **强调色**: 用于CTA按钮、重要提示的颜色
- **背景色**: 页面主背景（亮色/暗色/渐变）
- **文字色**: 主要文字颜色

### 分析方法
1. 从页面截图中识别主要色彩区域
2. 使用HSL色彩空间分析色相分布
3. 判断色彩模式：
   - 单色系 (Monochromatic): 同一色相不同明度
   - 双色系 (Dual-tone): 两种主色搭配
   - 多色系 (Multi-color): 三种以上颜色
   - 渐变色 (Gradient): 色彩过渡效果

### 输出格式
```
色彩模式: [单色/双色/多色/渐变]
主色调: #XXXXXX (HSL: H° S% L%)
辅助色: #XXXXXX, #XXXXXX
强调色: #XXXXXX
背景色: #XXXXXX (亮色/暗色)
色彩饱和度: [高/中/低]
```

---

## 维度2: 线条分析 (Stroke Analysis)

### 提取内容
- **线宽**: 细线(≤1px) / 中等(1.5-2px) / 粗线(≥2.5px)
- **端点**: 平头(butt) / 圆头(round) / 方头(square)
- **连接**: 尖角(miter) / 圆角(round) / 斜角(bevel)
- **断点**: 有断点(缺口风格) / 无断点(连续)
- **一致性**: 线宽是否统一

### 分析方法
1. 观察页面中图标和装饰元素的线条特征
2. 测量线条粗细的相对比例
3. 判断是否有统一的线条规范

### 输出格式
```
线宽: [细/中/粗] (约Xpx)
端点: [平头/圆头/方头]
圆角: [无/小(2px)/中(4px)/大(8px+)/全圆]
断点: [有/无]
线条一致性: [高/中/低]
```

---

## 维度3: 形状分析 (Shape Analysis)

### 提取内容
- **形状语言**: 几何(Geometric) / 有机(Organic) / 混合(Mixed)
- **比例倾向**: 方正(Rectangular) / 圆润(Rounded) / 修长(Elongated)
- **对称性**: 对称(Symmetric) / 不对称(Asymmetric)
- **复杂度**: 简约(Simple) / 中等(Moderate) / 复杂(Complex)
- **视角**: 正面(Front) / 侧面(Side) / 等距(Isometric)

### 分析方法
1. 观察图标和UI元素的形状特征
2. 判断形状是偏向直线还是曲线
3. 评估整体视觉的几何感或有机感

### 输出格式
```
形状语言: [几何/有机/混合]
比例: [方正/圆润/修长]
对称性: [对称/不对称]
复杂度: [简约/中等/复杂]
视角: [正面/侧面/等距]
```

---

## 维度4: 质感分析 (Texture Analysis)

### 提取内容
- **阴影**: 无(None) / 轻阴影(Light) / 重阴影(Heavy) / 内阴影(Inner)
- **渐变**: 无(None) / 线性(Linear) / 径向(Radial) / 多色(Multi-stop)
- **透明度**: 不透明(Opaque) / 半透明(Translucent) / 毛玻璃(Frosted)
- **纹理**: 无(None) / 噪点(Noise) / 图案(Pattern) / 材质(Material)
- **立体感**: 扁平(Flat) / 轻立体(Subtle 3D) / 强立体(Strong 3D)

### 分析方法
1. 观察按钮、卡片、图标是否有阴影效果
2. 判断色彩是纯色填充还是渐变
3. 检查是否有半透明叠加效果
4. 评估整体的立体程度

### 输出格式
```
阴影: [无/轻/重/内阴影]
渐变: [无/线性/径向/多色]
透明度: [不透明/半透明/毛玻璃]
纹理: [无/噪点/图案/材质]
立体感: [扁平/轻立体/强立体]
```

---

## 维度5: 整体调性分析 (Tone Analysis)

### 提取内容
- **行业属性**: 科技(Tech) / 金融(Finance) / 教育(Education) / 电商(E-commerce) / 社交(Social) / 游戏(Gaming) / 其他
- **目标用户**: 儿童(Kids) / 年轻人(Young) / 商务(Business) / 通用(General)
- **品牌气质**: 专业(Professional) / 活泼(Playful) / 高端(Premium) / 亲和(Friendly) / 极简(Minimal)
- **情感倾向**: 冷静(Calm) / 热情(Passionate) / 可信(Trustworthy) / 创意(Creative)

### 分析方法
1. 综合以上所有维度进行整体判断
2. 结合行业特征和目标用户群体
3. 参考色彩心理学和设计趋势

### 输出格式
```
行业属性: [行业类型]
目标用户: [用户群体]
品牌气质: [气质类型]
情感倾向: [情感类型]
```

## 综合推荐

基于以上5个维度的分析结果，给出图标风格推荐：

### 推荐逻辑

```
IF 质感.立体感 == "扁平" AND 线宽 == "细" THEN 推荐: "线性描边风 (S6)"
IF 质感.渐变 != "无" AND 色彩.饱和度 == "高" THEN 推荐: "活力渐变风 (S2)"
IF 质感.透明度 == "毛玻璃" THEN 推荐: "毛玻璃新拟态风 (S3)"
IF 质感.立体感 == "强立体" THEN 推荐: "3D立体风 (S4)"
IF 形状.形状语言 == "有机" AND 线宽 == "不规则" THEN 推荐: "手绘插画风 (S5)"
IF 色彩.色彩模式 == "双色" AND 质感 == "扁平" THEN 推荐: "双色双调风 (S7)"
IF 行业 == "游戏" OR 形状 == "方块化" THEN 推荐: "像素复古风 (S8)"
IF 品牌气质 == "专业" AND 质感 == "扁平" THEN 推荐: "现代极简风 (S1)"
```

### 输出格式
```
📐 推荐图标风格: [风格名称]
📐 推荐图标类型: [线性/面性/线面结合]
📐 推荐色系: [色系名称或自定义色值]
📐 推荐尺寸: [默认尺寸]
📐 置信度: [高/中/低]
```
